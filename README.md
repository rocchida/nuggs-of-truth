# Nuggs of Truth

Count the boot, ball, bell and bone shapes in your nugget box and get your fortune.

A plain HTML/CSS/JS page with no build step. Open `index.html` in a browser to run it locally.

**To edit the fortunes,** change `fortunes.js`. Each list has a comment saying when it is shown.

**Analytics.** Visits are counted with [GoatCounter](https://www.goatcounter.com) (no cookies, no personal data). The dashboard at https://drocky.goatcounter.com shows visit counts, countries, referrers, and two kinds of events: `reveal-<reading>` each time someone reveals a fortune, and `share`. To point it at a different GoatCounter site, change the `data-goatcounter` URL at the bottom of `index.html`. Visits from `localhost` are not counted.
